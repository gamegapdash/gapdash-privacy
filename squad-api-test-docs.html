Squad Challenge — Phase 1 API QC Guide

Hướng dẫn test từng API bằng Postman. Dành cho QC verify backend Phase 1 trước khi tích hợp client.

Phase 1 — Backend API Prefix: /api Auth: Bearer JWT Collection: documentation/postman/

Tổng quan

Squad Challenge là chế độ đua nhóm bất đồng bộ (tối đa 5 người). Host tạo squad, mời thành viên, bắt đầu phiên có thời hạn; mỗi người chơi độc lập và nộp điểm; khi hết giờ server chốt bảng xếp hạng.

Trạng thái squadÝ nghĩaAPI liên quan
waitingĐang chờ thành viên, chưa startInvite, Accept, Join by code, Start
activePhiên đang chạySubmit run, Leaderboard, Active session
completedPhiên đã kết thúcHistory list, History detail
expiredHết hạn 24h ở trạng thái waitingJoin/Start bị từ chối
Phạm vi Phase 1: Chỉ test API backend. Chưa có UI client, push notification (Phase 2+). Guest account được phép tạo/join squad.

Chuẩn bị Postman

  1. Import 2 file trong thư mục documentation/postman/:
    • GapDash-Squad-Challenge.postman_collection.json
    • GapDash-Squad-Challenge.postman_environment.json
  2. Chọn environment Gap Dash — Dev (Squad) (góc trên phải Postman).
  3. Sửa biến baseUrl — ví dụ staging/prod: https://prod-game.gapdasher.com (không có / cuối).
  4. Đặt hostDeviceId và memberDeviceId là 2 chuỗi khác nhau, chưa dùng trước đó nếu reset env.
  5. Chạy folder 00 Setup — Auth trước mọi test Squad.

Chi tiết thêm: documentation/postman/POSTMAN_SETUP.md

A. Auth — Setup (tiên quyết)

Tất cả Squad API yêu cầu header: Authorization: Bearer <accessToken>

POST /api/auth/guest-login

Mục đích: Tạo hoặc đăng nhập lại guest host. Collection: 1. Guest Login — Host

Headers
Content-Type: application/json
Body — guest mới (device_id chưa tồn tại trên server)
{
  "device_id": "{{hostDeviceId}}"
}
Body — guest cũ (device_id đã tồn tại)
{
  "device_id": "{{hostDeviceId}}",
  "guest_token": "{{hostGuestToken}}"
}
Response thành công
HTTPTrường hợp
201Guest mới — có thêm guest_token
200Guest cũ — chỉ có accessToken, refreshToken
{
  "success": true,
  "email": "...@guest.gapdash.local",
  "accessToken": "eyJ...",
  "refreshToken": "eyJ...",
  "guest_token": "eyJ..."   // chỉ lần tạo mới
}
Tiêu chí pass
  • Status 200 hoặc 201
  • accessToken được lưu vào hostToken
  • Lần đầu: guest_token lưu vào hostGuestToken
Lỗi thường gặp
HTTPMessageNguyên nhân
401guest_token required for returning guestDevice_id cũ nhưng đã xóa hostGuestToken → đổi hostDeviceId mới
401Invalid guest tokenguest_token sai hoặc hết hạn
POST /api/auth/guest-login

Mục đích: Guest thứ 2 (member). Collection: 2. Guest Login — Member. Logic giống host, dùng memberDeviceId / memberGuestToken / memberToken.

Tiêu chí pass
  • Status 200 hoặc 201
  • memberToken được lưu
  • memberDeviceId khác hostDeviceId
GET /api/users/me

Mục đích: Lấy id của member để invite. Collection: 3. Get Member Profile

Auth
Authorization: Bearer {{memberToken}}
Response mẫu
{
  "id": "377",
  "full_name": "Guestabc123",
  "email": "...",
  "league": "beginner",
  "gem": 0,
  "level": 1,
  "fuel_cell": 100
}
Quan trọng: Response không có public_id. Invite phải dùng user_id (giá trị id), không dùng username/public_id trừ khi biết full_name.
Tiêu chí pass
  • Status 200
  • memberUserId = giá trị field id

B. Squad APIs

Base path: {{baseUrl}}/api/squads. Tất cả endpoint dưới đây (trừ auth) cần Bearer token.

POST /api/squads

Mục đích: Host tạo squad mới. Collection: 1. Create Squad

Auth
Authorization: Bearer {{hostToken}}
Body
{
  "name": "Postman Test Squad",       // bắt buộc, max 30 ký tự
  "avatar_id": 1,                     // optional
  "duration_minutes": 15,             // bắt buộc: 15 | 30 | 60 | 120
  "map": "japan",                     // bắt buộc, max 50 ký tự
  "difficulty": "EASY"                // optional: EASY | MEDIUM | HARD
}
Response thành công — 200/201
{
  "squad": {
    "id": "uuid...",
    "name": "Postman Test Squad",
    "status": "waiting",
    "invite_code": "ABC123",          // 6 ký tự, auto-save inviteCode
    "max_members": 5,
    "duration_minutes": 15,
    "map": "japan",
    "host_user_id": "...",
    "expires_at": "..."               // +24h từ lúc tạo
  },
  "members": [ ... ],                 // host đã accepted
  "session": null
}
Tiêu chí pass
  • Status 200 hoặc 201
  • squad.status = waiting
  • squad.id và squad.invite_code được lưu env
  • Host có trong members với status: accepted, is_host: true
GET /api/squads/:id

Mục đích: Xem chi tiết squad. Collection: 2. Get Squad Detail

URL
{{baseUrl}}/api/squads/{{squadId}}
Auth
Authorization: Bearer {{hostToken}}
Tiêu chí pass
  • Status 200
  • squad.status = waiting (trước Start)
  • session = null (chưa start)
Lỗi
HTTPMessage
404Squad not found
403You are not a member of this squad
POST /api/squads/:id/invite

Mục đích: Host mời user vào squad. Collection: 3. Invite Member

Auth
Authorization: Bearer {{hostToken}}
Body (khuyến nghị)
{ "user_id": "{{memberUserId}}" }
Body (thay thế)
{ "username": "Guestabc123" }   // public_id hoặc full_name
Điều kiện
  • Chỉ host được gọi
  • Squad phải waiting
  • Tối đa 5 thành viên (accepted + invited)
Tiêu chí pass
  • Status 200/201
  • Member xuất hiện trong response với status: invited
Lỗi
HTTPMessage
400user_id or username is required
404User not found
400Cannot invite yourself
400User is already in this squad
403Only the host can perform this action
400Squad is not in waiting status
400Squad is full
POST /api/squads/:id/accept

Mục đích: Member chấp nhận lời mời. Collection: 4. Accept Invite (member)

Auth
Authorization: Bearer {{memberToken}}
Body

Không có body.

Tiêu chí pass
  • Status 200/201
  • Member có status: accepted, joined_at có giá trị
  • Ít nhất 2 member accepted (host + member) — đủ điều kiện Start
Lỗi
HTTPMessage
400No pending invite for this squad
400Squad is not in waiting status
POST /api/squads/:id/decline

Mục đích: Member từ chối lời mời. Chưa có trong collection mặc định — test manual nếu cần.

Auth
Authorization: Bearer {{memberToken}}
Response thành công
{ "success": true }
Tiêu chí pass
  • Status 200
  • success: true
  • Gọi lại Get Detail — member status: declined
POST /api/squads/join/:code

Mục đích: Member tự join bằng mã invite (không qua invite API). Collection: folder 03 Alternate — Join by Code

URL
{{baseUrl}}/api/squads/join/{{inviteCode}}
Auth
Authorization: Bearer {{memberToken}}
Điều kiện
  • Squad waiting, chưa hết expires_at
  • Chưa Start Session
  • Member chưa là thành viên accepted
Tiêu chí pass
  • Status 200/201
  • Member status: accepted ngay (không cần Accept)
400 Squad is no longer accepting members — ĐÚNG KỲ VỌNG nếu chạy sau Happy Path đã Start (squad = active).
Lỗi khác
HTTPMessage
404Invalid invite code
400Squad invite has expired
400Squad is full
POST /api/squads/:id/start

Mục đích: Host bắt đầu phiên đua. Collection: 5. Start Session (host)

Auth
Authorization: Bearer {{hostToken}}
Điều kiện
  • Chỉ host
  • Squad waiting
  • ≥ 2 member accepted (host + ít nhất 1 người)
Response — session mới
{
  "squad": { "status": "active", ... },
  "session": {
    "id": "...",
    "status": "active",
    "started_at": "...",
    "ended_at": "...",
    "duration_minutes": 15,
    "seconds_remaining": 900
  }
}
Tiêu chí pass
  • Status 200/201
  • session.status = active
  • sessionId được lưu env
  • squad.status = active
Lỗi
HTTPMessage
400At least 2 accepted members required to start
403Only the host can perform this action

Mục đích: Lấy phiên đang active của user hiện tại. Collection: 6. Get Active Session

Response khi có phiên
{

    "squad_id": "...",

Tiêu chí pass (sau Start)
  • Status 200

  • session_id khớp sessionId env
POST /api/squads/:id/runs

Mục đích: Nộp kết quả chơi trong phiên active. Collection: 7. Submit Run — Host, 8. Submit Run — Member

Body
{
  "distance": 12000,        // bắt buộc, integer > 0
  "jump_count": 150,        // bắt buộc, >= 0
  "flying_time": 30,        // bắt buộc, >= 0
  "gems": 42,               // optional
  "fuel_cell": 2,           // optional
  "difficulty": "EASY",     // optional
  "map": "japan"            // optional, default từ squad
}
Response thành công
{
  "success": true,
  "run": {
    "id": "...",
    "distance": 12000,
    "gems": 42,
    "jump_count": 150,
    "flying_time": 30,
    "submitted_at": "..."
  }
}
Tiêu chí pass
  • Status 200/201, success: true
  • Mỗi user chỉ submit 1 lần / session
  • Host distance > member distance (trong collection) → host rank #1
Lỗi
HTTPMessage
400No active session for this squad
400Run already submitted for this session
400Session has ended
403You must be an accepted squad member

Mục đích: Bảng xếp hạng phiên hiện tại. Collection: 9. Leaderboard

Response

GET /api/squads/history/:sessionId

Mục đích: Chi tiết phiên đã kết thúc + full leaderboard. Collection: 11. History Detail

Điều kiện
  • Session phải status: completed
  • User phải là member accepted của squad đó
  • Session kết thúc khi: ended_at qua + cron server (~1 phút/lần)
Response thành công
{
  "squad": { ... },
  "session": { "status": "completed", ... },
  "leaderboard": [ ... ]
}
404 Session not found ngay sau Happy Path — ĐÚNG KỲ VỌNG vì session vẫn active. Đợi hết duration_minutes (tối thiểu 15 phút) + ~1 phút rồi test lại.
Tiêu chí pass (khi đủ thời gian)
  • Status 200
  • session.status = completed
  • Leaderboard có rank đã chốt

E. Troubleshooting

Triệu chứngNguyên nhânCách xử lý
